# Bazilio Portas

App de controle de serviços, prestadores e NFS-e para assentamento de portas.

## Acessar / Instalar no celular

1. Abra no navegador do celular:  
   **https://josubazilio-sudo.github.io/bazilio-portas/**

2. No **Android** (Chrome):  
   Menu ⋮ > **Instalar app** ou **Adicionar à tela inicial**

3. No **iPhone** (Safari):  
   Compartilhar > **Adicionar à Tela de Início**
